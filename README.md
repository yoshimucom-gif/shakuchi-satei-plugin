# 借地権の目安査定（WordPressプラグイン）

所在地・土地の面積・借地権割合と連絡先を受け付け、その場で借地権の売却価格の目安を返すフォーム。

- 置き方：`[shakuchi_satei]`
- 目安額＝更地価格（国交省 不動産情報ライブラリの土地の取引事例の㎡単価の中央値×面積）×借地権割合×掛け率（既定70%）
- 借地権割合が「わからない」ときは60〜70%の幅で出す
- 申し込みは専用テーブルに保存し、担当者へ通知・申込者へ目安額つきの受付メール
- 管理画面：借地権の目安査定 → 申込一覧（CSV書き出し）／設定
- 国交省APIのキーは、空欄なら同じサイトの「借地権の計算ツール」「相場データ」のキーを使う

## 更新の配り方

```
py build.py 1.0.1 "・変更点"
git add -A && git commit -m "v1.0.1" && git push
```

update.json を見て、入れてある全サイトの管理画面に更新が出る。
